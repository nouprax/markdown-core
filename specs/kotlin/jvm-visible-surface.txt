# Kotlin declarations that ordinary Java can reach and that are NOT public API.
#
# `internal` lowers to `public final` on the JVM whenever the declaration is
# reached from another compilation unit, so this list is not a set of mistakes
# to fix one by one -- most of it cannot be made package-private without
# collapsing the multiplatform source-set split. It is a REVIEWED RECORD, and
# `scripts/audit-kotlin-jvm-surface.sh` fails on anything added to the actual
# surface that is not written down here.
#
# `checkKotlinAbi` does not overlap with this: its dump is the Kotlin API, and
# every name below is absent from it by construction.
#
# JniParser is deliberately absent: the holder is package-private, its raw
# payload method carries @JvmSynthetic, and the audit checks both properties.

# `when` over an enum compiles to a lookup table in a nested class.
JniTreeDecoder$WhenMappings
TreeDumperKt$WhenMappings
WalkingDriver$WhenMappings

# File facades for top-level declarations. The class is public because the file
# has top-level members; the members themselves are internal and name-mangled.
ImmutableListKt
PlatformParser_jvmKt
TreeDumperKt
JniPayloadDecoderKt
JniMarkupDecoderKt

# The companion of a package-private class. Reachable in name only: every
# member is internal, and the owning class is not public.
ReadOnlyList$Companion

# The private JVM/Android wire protocol. The shared JNI source set declares
# these internal types, so Kotlin emits public bytecode even though they are
# absent from the Kotlin API. None of these names or bytes are stable API.
JniPayloadDecoder
JniNodeKind
JniNodeKind$Companion
JniPayloadReader

# Nested action records under the package-private WalkAction owner. javap
# reports public nested bytecode, but the enclosing type and ActionPhase are
# inaccessible to ordinary Java callers. These already exist in the M5
# compiled surface; M6 reconciles the ledger while replacing the table model.
WalkAction$Node
WalkAction$CitationValue
WalkAction$FootnoteValue
WalkAction$SpecimenValue

# P2's reference-definition resource and shared attribute merge operations are
# consumed by both JNI and Native materializers. Their internal Kotlin model
# was already present before P5/P6; this audit records its JVM lowering.
AttributesKt
DefinitionResource
