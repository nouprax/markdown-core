The ratio $r = I_c / I_m$ is reported per stage, and the aggregate

$$
R = \frac{\sum_i I_{c,i}}{\sum_i I_{m,i}}
$$

is reported over the concatenated corpus.

LaTeX delimiters carry the same content:

\[
S = \sum_{i=1}^{n} w_i x_i
\]

Inline $x^2 + y^2 = z^2$ and $\alpha\beta\gamma$ appear beside ordinary
`code spans` and *emphasis*, so the formula scanner shares the line with
the code scanner.
